Michael Akorede Fatayo

MSc Candidate, Computer Science, Lead City University, Ibadan, Nigeria

CV / Email / ORCID / Google Scholar / GitHub / LinkedIn

I work on real-time machine learning systems for financial fraud detection, with a focus on evaluation protocols that hold up once a model has to run in production: causally-correct features, temporal (not random) train/test splits, and ablations that separate genuine signal from artifacts of the benchmark itself.

My MSc thesis, FraudShield, builds a streaming fraud-detection architecture (Kafka, Spark Streaming, Redis, XGBoost) evaluated on the full 6.3M-transaction PaySim dataset, including a feature-group ablation that identifies how much of its near-perfect accuracy is genuine learned signal versus an artifact of the dataset.

Research interests: real-time ML systems, fraud and anomaly detection, imbalanced classification, causal feature engineering, streaming architectures.
